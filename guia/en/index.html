In brief

This repository brings together the exercises from the INEMA series “From Chat to Agent Creator.” It has four sequences, in order: use an agent in the terminal, build a personal assistant on Telegram, put tasks in a queue that runs on its own, and automate social media with your approval. It’s for people who already use AI chat and want it to work independently. Each exercise has a “Done when” criterion to show you when you’re finished. You need a computer, a terminal, and Claude Code or Codex.

What it is

Four steps to move beyond chat

In chat, you’re the driver the whole time: ask, copy, paste, adjust. An agent reads your files, carries out tasks, and keeps working while you do something else. The shift is about changing where you work: from chat to the system.

🪜 Order matters

Without sequence 1, the others won’t hold up. Start with folders and the terminal, then the assistant, then the queue, and only then social media.

⚙️ No magic

Nothing renders while you sleep if the system isn’t running correctly. Without a queue and an approval gate, social media automation just means posting mistakes faster.

✅ Done when

Each exercise ends with a criterion you can check: the page opens, git status doesn’t show .env, the bot remembers you.

Tool · homegrown queue

A task queue in 30 lines

Before using inemaccbot, understand the idea with ferramentas/fila-caseira.sh from this repository. Each file in entrada/ becomes a task; the response goes to feito/; any task that errors goes to falhou/. Running it again picks up only what remains.

entrada/→ rodando/→ feito/ or falhou/ 
git clone https://github.com/inematds/jornada-agentes.git
cd jornada-agentes
mkdir -p fila/entrada
echo "Summarize what a task queue is in 5 lines." > fila/entrada/01.md
echo "List 3 risks of leaving an agent running on its own." > fila/entrada/02.md
./ferramentas/fila-caseira.sh fila          # default engine: claude
./ferramentas/fila-caseira.sh fila codex    # or Codex, through your subscription

Resuming: if a run stops or you press Ctrl+C, the task in rodando/ returns to entrada/ on the next run. It’s the same idea as inemaccbot’s durable queue, in pocket size. View the script
