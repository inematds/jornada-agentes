En resumen

Este repositorio reúne los ejercicios de la serie INEMA «De chat a creador de agentes». Son cuatro secuencias, en orden: usar el agente en la terminal, crear un asistente personal en Telegram, poner tareas en una cola que funciona sola y automatizar redes sociales con tu aprobación. Es para quienes ya usan el chat de IA y quieren que trabaje por su cuenta. Cada ejercicio tiene un «Listo cuando» que indica si lo terminaste. Necesitas una computadora, la terminal y Claude Code o Codex.

Qué es

Cuatro pasos para salir del chat

En el chat eres quien conduce todo el tiempo: preguntas, copias, pegas, ajustas. Un agente lee tus archivos, ejecuta tareas y sigue trabajando mientras haces otra cosa. El cambio está en pasar del chat al sistema.

🪜 El orden importa

Sin la secuencia 1, las demás no se sostienen. Primero, carpeta y terminal; después, el asistente; luego, la cola, y solo entonces, las redes.

⚙️ Sin milagros

No habrá una renderización mientras duermes si el sistema no funciona correctamente. Sin cola y sin puerta, automatizar redes sociales significa publicar mal más rápido.

✅ Listo cuando

Cada ejercicio termina con un criterio que puedes comprobar: la página abre, git status no muestra .env, el bot se acuerda de ti.

Herramienta · cola casera

Una cola de tareas en 30 líneas

Antes de inemaccbot, entiende la idea con ferramentas/fila-caseira.sh de este repositorio. Cada archivo en entrada/ se convierte en una tarea; la respuesta va a feito/; la que dé error va a falhou/. Al ejecutarlo de nuevo, solo toma lo que quedó pendiente.

entrada/→ rodando/→ feito/ o falhou/ 
git clone https://github.com/inematds/jornada-agentes.git
cd jornada-agentes
mkdir -p fila/entrada
echo "Resume en 5 líneas qué es una cola de tareas." > fila/entrada/01.md
echo "Enumera 3 riesgos de dejar un agente funcionando sin supervisión." > fila/entrada/02.md
./ferramentas/fila-caseira.sh fila          # motor predeterminado: claude
./ferramentas/fila-caseira.sh fila codex    # o Codex, con tu suscripción

Reanudación: si la ejecución se interrumpe o presionas Ctrl+C, la tarea que estaba en rodando/ vuelve a entrada/ en la próxima ejecución. Es la misma idea de la cola duradera de inemaccbot, en tamaño de bolsillo. Ver el script
