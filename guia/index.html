Em resumo

Este repositório reúne os exercícios da série INEMA "Do chat ao criador de agentes". São quatro sequências, em ordem: usar o agente no terminal, montar um assistente pessoal pelo Telegram, colocar tarefas numa fila que roda sozinha e automatizar redes sociais com aprovação sua. Serve para quem já usa o chat da IA e quer que ela trabalhe por conta própria. Cada exercício tem um "pronto quando" que diz se você terminou. Você precisa de um computador, do terminal e do Claude Code ou do Codex.

O que é

Quatro degraus para sair do chat

No chat você é o motorista o tempo todo: pergunta, copia, cola, ajusta. Um agente lê os seus arquivos, executa tarefas e continua trabalhando enquanto você faz outra coisa. A virada é mudar de lugar: do chat para o sistema.

🪜 A ordem importa

Sem a sequência 1, as outras não ficam de pé. Primeiro pasta e terminal, depois o assistente, depois a fila, e só então as redes.

⚙️ Sem milagre

Não existe render enquanto você dorme se o sistema não roda correto. Sem fila e sem portão, automatizar rede social vira postar errado mais rápido.

✅ Pronto quando

Cada exercício termina num critério que você confere: a página abre, o git status não mostra o .env, o bot lembra de você.

Ferramenta · fila caseira

Uma fila de tarefas em 30 linhas

Antes do inemaccbot, entenda a ideia com o ferramentas/fila-caseira.sh deste repositório. Cada arquivo em entrada/ vira uma tarefa; a resposta vai para feito/; a que der erro vai para falhou/. Rodar de novo só pega o que sobrou.

entrada/→ rodando/→ feito/ ou falhou/ 
git clone https://github.com/inematds/jornada-agentes.git
cd jornada-agentes
mkdir -p fila/entrada
echo "Resuma em 5 linhas o que é uma fila de tarefas." > fila/entrada/01.md
echo "Liste 3 riscos de deixar um agente rodando sozinho." > fila/entrada/02.md
./ferramentas/fila-caseira.sh fila          # motor padrão: claude
./ferramentas/fila-caseira.sh fila codex    # ou o Codex, pela sua assinatura

Retomada: se a rodada cair ou você apertar Ctrl+C, a tarefa que estava em rodando/ volta para entrada/ na próxima execução. É a mesma ideia da fila durável do inemaccbot, em tamanho de bolso. Ver o script
