Un agente dentro de tus carpetas

Con unos pocos comandos sales del chat y pones a Claude Code o Codex a trabajar en tus archivos.

Ver el video ↓Abrir OSWork Quick →

OSWork es el paso que separa a quienes usan inteligencia artificial de quienes crean con ella. Aprendes seis comandos de terminal, organizas el trabajo en carpetas con archivos de texto en markdown y escribes un AGENTS.md con las reglas del proyecto. Luego llamas al agente dentro de la carpeta, le das una tarea y revisas el resultado. Por último, añades una red de seguridad: Git para deshacer errores y un archivo de secretos para las claves.

Secuencia 1 — Del chat a la terminal: OSWork

Por qué el chat se queda corto

En el chat, te conviertes en mensajero

La IA del chat no ve tus archivos y olvida lo que le explicaste ayer.

Cada respuesta debe copiarse y pegarse en el lugar correcto. Pasas el día llevando texto de la ventana al trabajo y de vuelta. OSWork muestra el recorrido por tres ventanas, Chat, Work y Desktop, y luego por la terminal, donde vive el agente.

Paso 2

Una carpeta por proyecto, un AGENTS.md

El secreto está en las carpetas. Dentro de cada una, hay archivos de texto en markdown.

AGENTS.md contiene las reglas del proyecto: quién eres, qué puede hacer el agente y qué no. El agente lee este archivo cada vez que empieza. Es como entregarle el manual a un empleado nuevo.

# Quién soy
Ana, contadora, atiendo a pequeñas empresas.

# Reglas de este proyecto
- Escribe en portugués, usa frases cortas.
- No borres archivos sin preguntar.
- Antes de terminar, di qué cambió y cómo puedo revisarlo.

# Qué hay aquí
- index.html: mi página
Paso 3

Tú das la tarea y el agente la hace

Entra en la carpeta del proyecto y llama a Claude Code (claude) o Codex (codex).

cd projetos/meu-primeiro-agente
claude        # o: codex
Lee AGENTS.md. Crea un index.html con una página sencilla sobre mí, usando la información que contiene.

Los archivos aparecen en la carpeta. Abre la página en el navegador, pide una corrección y vuelve a revisarla. No programaste nada: diste la tarea, revisaste el resultado y decidiste. Eso es gestión.

Paso 4

La red de seguridad: Git, secretos y VPS

Equivocarse sale barato cuando puedes volver atrás.

Git guarda cada versión

Haz un commit antes de cada cambio importante. Si el agente se equivoca, git restore recupera el archivo.

Secretos fuera del texto

Las claves y contraseñas van en un archivo .env, incluido en .gitignore. Nunca dentro del código.

Telegram y VPS

Al final del recorrido, Telegram se convierte en la interfaz y una VPS permite que el agente siga funcionando con tu computadora apagada.

git init
git add .
git commit -m "primeira versão"
# ¿no te gustó el cambio del agente?
git restore index.html

Ejercicios de esta secuencia

Hazlos en orden. Cada ejercicio tiene un «listo cuando»: pasa al siguiente solo cuando se cumpla.

  1. E1

    Tu primera carpeta desde la terminal · 10 min

    Listo cuando: Llegas a la carpeta usando solo la terminal y sabes decir en qué carpeta estás.

  2. E2

    El manual del empleado: AGENTS.md · 15 min

    Listo cuando: El archivo existe y tiene al menos tres reglas escritas por ti.

  3. E3

    La primera tarea · 15 min

    Listo cuando: La página se abre en el navegador y le pediste al agente al menos una corrección.

  4. E4

    La red de seguridad: Git · 20 min

    Listo cuando: Deshiciste un cambio del agente con un comando, sin entrar en pánico.

  5. E5

    El secreto no va en el texto · 10 min

    Listo cuando: git status no muestra .env.

  6. E6

    El agente lee tus archivos · 20 min

    Listo cuando: Encontraste en el original al menos dos de las frases mencionadas en el resumen.
