Um agente dentro das suas pastas

Com meia dúzia de comandos você sai do chat e coloca o Claude Code ou o Codex para trabalhar nos seus arquivos.

Assistir ao vídeo ↓Abrir o OSWork Quick →

O OSWork é o degrau que separa quem usa inteligência artificial de quem cria com ela. Você aprende seis comandos de terminal, organiza o trabalho em pastas com arquivos de texto em markdown e escreve um AGENTS.md com as regras do projeto. Depois chama o agente dentro da pasta, dá uma tarefa e confere o resultado. Por fim, coloca uma rede de segurança: o Git para desfazer erros e um arquivo de segredos para as chaves.

O roteiro do vídeo, cena por cena
  1. Cena 1Um agente dentro das suas pastas

    Com meia dúzia de comandos você sai do chat e coloca um agente para trabalhar dentro das suas pastas. Essa é a sequência um, o OSWork, e ela separa quem usa inteligência artificial de quem cria com ela. Neste vídeo: por que o chat trava, os passos do terminal, e no fim, o primeiro pedido para o seu agente.

  2. Cena 2Você vira o carteiro

    No chat, a inteligência artificial não enxerga os seus arquivos, esquece o que você explicou ontem, e cada resposta precisa ser copiada e colada. Você vira o carteiro entre a janela e o seu trabalho. O OSWork mostra o caminho em três janelas: o Chat, o Work e o Desktop. E depois o terminal, onde o agente mora.

  3. Cena 3Só outra janela

    O terminal assusta, mas é só outra janela. Você digita um comando e ele responde. Com seis comandos você navega: ver onde está, listar, entrar numa pasta, voltar, criar uma pasta, abrir um arquivo. Não é programar. É andar pelas suas pastas sem o mouse.

  4. Cena 4Uma pasta, um AGENTS.md

    O segredo está nas pastas. Uma pasta por projeto, e dentro dela arquivos de texto em markdown. Um deles é o AGENTS ponto MD: as regras do projeto, quem você é, o que pode e o que não pode. O agente lê esse arquivo toda vez que começa. É como entregar o manual para um funcionário novo.

  5. Cena 5Você dá a tarefa

    Agora o agente. Você entra na pasta do projeto e chama o Claude Code ou o Codex. Pede: crie uma página simples sobre mim e um arquivo com as regras deste projeto. Os arquivos aparecem na pasta. Você não programou nada. Deu a tarefa, conferiu o resultado e decidiu. Isso é gestão.

  6. Cena 6Git, segredos e VPS

    Depois vem a segurança. O Git guarda cada versão, e se o agente errar, você volta. As chaves e senhas ficam fora do texto, num arquivo de segredos. E no fim do percurso, o Telegram vira a interface, e uma VPS deixa o agente rodando mesmo com o seu computador desligado.

  7. Cena 7O degrau que destrava tudo

    Esse é o degrau que destrava as outras três sequências: o Jarvis, as filas e as redes no automático. O OSWork completo, comando por comando, está no INEMA ponto CLUB, aberto e gratuito. Abra o terminal hoje, crie a sua primeira pasta, e dê a primeira tarefa para o seu agente.

Por que o chat trava

No chat, você vira o carteiro

A IA do chat não enxerga os seus arquivos e esquece o que você explicou ontem.

Cada resposta precisa ser copiada e colada no lugar certo. Você passa o dia levando texto da janela para o trabalho e de volta. O OSWork mostra o caminho em três janelas, o Chat, o Work e o Desktop, e depois o terminal, onde o agente mora.

Passo 2

Uma pasta por projeto, um AGENTS.md

O segredo está nas pastas. Dentro de cada uma, arquivos de texto em markdown.

O AGENTS.md traz as regras do projeto: quem você é, o que o agente pode fazer e o que não pode. O agente lê esse arquivo toda vez que começa. É como entregar o manual para um funcionário novo.

# Quem sou
Ana, contadora, atendo pequenas empresas.

# Regras deste projeto
- Escreva em português, frases curtas.
- Não apague arquivos sem perguntar.
- Antes de terminar, diga o que mudou e como eu confiro.

# O que tem aqui
- index.html: minha página
Passo 3

Você dá a tarefa, o agente faz

Entre na pasta do projeto e chame o Claude Code (claude) ou o Codex (codex).

cd projetos/meu-primeiro-agente
claude        # ou: codex
Leia o AGENTS.md. Crie um index.html com uma página simples sobre mim, usando o que está lá.

Os arquivos aparecem na pasta. Abra a página no navegador, peça uma correção e confira de novo. Você não programou nada: deu a tarefa, conferiu o resultado e decidiu. Isso é gestão.

Passo 4

A rede de segurança: Git, segredos e VPS

Errar fica barato quando você consegue voltar.

Git guarda cada versão

Um commit antes de cada mudança grande. Se o agente errar, git restore volta o arquivo.

Segredos fora do texto

Chaves e senhas ficam num arquivo .env, listado no .gitignore. Nunca dentro do código.

Telegram e VPS

No fim do percurso, o Telegram vira a interface e uma VPS deixa o agente rodando com o seu computador desligado.

git init
git add .
git commit -m "primeira versão"
# não gostou da mudança do agente?
git restore index.html
Pratique

Exercícios desta sequência

Faça na ordem. Cada exercício tem um "pronto quando": só passe para o próximo quando ele for verdade.

  1. E1

    Sua primeira pasta pelo terminal · 10 min

    Pronto quando: você chega até a pasta só pelo terminal e sabe dizer em que pasta está.

  2. E2

    O manual do funcionário: AGENTS.md · 15 min

    Pronto quando: o arquivo existe e tem pelo menos três regras escritas por você.

  3. E3

    A primeira tarefa · 15 min

    Pronto quando: a página abre no navegador e você pediu pelo menos uma correção ao agente.

  4. E4

    A rede de segurança: Git · 20 min

    Pronto quando: você desfez uma mudança do agente com um comando, sem pânico.

  5. E5

    Segredo não entra no texto · 10 min

    Pronto quando: o git status não mostra o .env.

  6. E6

    O agente lê os seus arquivos · 20 min

    Pronto quando: você achou no original pelo menos duas das frases citadas no resumo.
