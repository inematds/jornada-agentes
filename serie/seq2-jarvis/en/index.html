Create your Jarvis

A personal assistant that talks with you on Telegram, remembers your conversations, and has the personality you choose.

Watch the video ↓Open INTELECTO →

INTELECTO is a personal assistant written from scratch in Python, small on purpose so you can read it, understand it and change it. It receives your messages on Telegram, thinks in an agent loop, searches memory, uses tools and replies with a model in the cloud (OpenRouter) or on your computer (Ollama). There is no installer: the agent builds yours from a briefing, with tests. It comes after OSWork because it uses the terminal, folders and a key stored in the right place.

Sequence 2 — Create your Jarvis with INTELECTO

What it is

Small on purpose

No heavy framework, no Docker, no web dashboard.

About 3,000 lines

Python code you can read in an afternoon. You'll understand what it does.

7 dependencies

Fewer pieces to install and almost nothing to break.

Truly yours

It runs on your computer. You no longer have to open a website to chat.

How it thinks

Telegram, agent, model

It's the same design as big assistants, only it's yours.

You on Telegram→INTELECTO receives it→Agent loop: memory and tools→Model generates a reply→Reply on Telegram

Cloud model (OpenRouter)

  • Large models, better answers.
  • Pay as you go, with your own key.
  • Doesn't depend on your computer's power.

Local model (Ollama)

  • Runs on your machine, with no cost per message.
  • Your data stays on your computer.
  • Needs memory and preferably a graphics card.
Install

Briefing, agent, and tests

INTELECTO has no installer: the agent builds your assistant from a briefing. Start by proving the repository's example.

git clone https://github.com/inematds/intelecto.git
cd intelecto/exemplo-jarvis
python3 -m unittest discover -s . -p 'test_*.py' -v
python3 smoke.py
1

Prove the example

Run the 9 tests and the smoke.py of the exemplo-jarvis. It needs no key and no internet.

2

Export the briefing

On the INTELECTO comparison page, tick the ingredients and download your .md briefing.

3

Create the Telegram bot

Open @BotFather, send /newbot, choose a name and a username, and copy the token into the .env.

4

Ask for the build

Hand the briefing to Claude Code or Codex and ask it to build from it and from doc/intelecto.md, with tests.

5

Send "hi"

Your bot replies with the name and the way of speaking you defined.

The token and keys stay only in the configuration file, never in text that goes into Git. That's the rule you learned in sequence 1.

Memory

It remembers you

Memory and personality are what make it your Jarvis.

It remembers what you talked about, saves what matters, and speaks the way you chose. Tell it on Monday that you close the sales report every week; on Tuesday, in a new conversation, ask what you do on Mondays. It's not a website that forgets everything when you close the tab.

Practice

Exercises in this sequence

Do them in order. Each exercise has a "ready when" criterion: move on only when it is true.

  1. E1

    Design your Jarvis before installing it · 15 min

    Ready when: the file fits on one screen and someone else would understand who your assistant is.

  2. E2

    The bot on Telegram · 10 min

    Ready when: you have the token and it doesn't appear in any file besides .env.

  3. E3

    Install · 30 min

    Ready when: you send "hi" and it replies with the name and style you chose.

  4. E4

    Memory test · 2 days

    Ready when: it remembers without you repeating yourself.

  5. E5

    Cloud or local · 20 min

    Ready when: you can say which model to use for what, using your own numbers.

  6. E6

    A real routine · 20 min

    Ready when: you used it 5 days in a row and wrote down what to improve.
